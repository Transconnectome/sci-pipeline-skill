# 사고 사례집 (세 연구 프로젝트, 2026-06 ~ 2026-10)

범례 — **P-draw**: 펜 궤적 드로잉 바이오마커 분류 프로젝트, **P-twin**: 문항 반응 기반 행동 디지털트윈 프로젝트, **P-prior**: 신경과학 지식을 모델·에이전트에 주입하는 프로젝트. 원 레포는 비공개다.

감사할 때 "같은 모양의 결함이 여기에도 있는가"를 대조하는 용도다. 각 사례는 한 줄 증상 → 원인 → 고친 방식 → 게이트.
