# 자료 계약 — <데이터셋 이름>

> 레포에 데이터 사전이 이미 있으면 이 파일을 만들지 말고 아래 항목을 그 사전에 채운다.
> 원칙: **계약을 어기는 입력은 halt한다. 자동 교정·재정렬·조용한 대치를 하지 않는다.**
> 검증은 문서가 아니라 코드(pandera·pydantic 또는 표준 라이브러리 검사)에 있어야 하고, 위반 시 예외로 끝나야 한다.

| 항목 | 규칙 | 위반 시 | 검증 코드 위치 |
|---|---|---|---|
| 식별자 | 형식, 정규화 함수 1개(공백·접두어·대소문자), 쓰기·읽기 동일 적용, 중복 금지 | halt | UNSET |
| 군집 연결 | 가족·기관·동일인 복수 id 연결 규칙 | halt | UNSET |
| 범주 변수 | 허용값 목록, 정규화 함수 1개, 모르는 값 | halt | UNSET |
| 라벨 | 허용값, 결측 처리(거부/명시 제외), 정수 캐스팅 금지 | halt | UNSET |
| 결측 부호 | 결측 코드 목록(미시행/중단/오답/사망 구분) | halt | UNSET |
| 시각 | timezone-aware, `측정 ≤ 이용 가능 ≤ 예측` | halt | UNSET |
| 순서 키 | 시퀀스 순서 = 시간 순서 | halt (재정렬 금지) | UNSET |
| 단위·형 | 단위·dtype·샘플링 간격 허용 범위 | halt (거짓 경보 먼저 점검) | UNSET |
| 빈 기록 | 측정이 하나도 없는 참가자 | halt | UNSET |
| 신규 개체 | 봉인 이후 처음 보는 id | halt | UNSET |
| 대체 자료 | 실자료 부재 시 합성·자리표시로 대체 | 금지 (사람 승인 + 명시 플래그 없이는 halt) | UNSET |
| 보관 위치 | 원자료·식별자는 Git 밖 승인 위치, `.gitignore` 확장자 범위 | 커밋 차단 | UNSET |

## 계약 시험 (각 항목마다 위반 fixture 1개 이상)

- [ ] id 끝 공백 / 접두어 변경 → halt
- [ ] 범주 대소문자·공백 혼용 → 하나로 정규화되거나 모르는 값이면 halt
- [ ] 라벨 NaN → halt (어느 아키텍처에서도)
- [ ] naive 시각 / 측정 > 이용 가능 → halt
- [ ] 순서 키 뒤섞음 → halt
- [ ] 행 순서만 섞은 정상 자료 → **통과** (거짓 경보 방지)
